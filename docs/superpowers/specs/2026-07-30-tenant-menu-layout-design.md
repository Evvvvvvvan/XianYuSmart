# 租户级菜单自定义设计

## 目标

为每个租户提供独立的菜单布局配置，支持拖动调整菜单模块及模块内菜单顺序，并同步优化桌面端、平板端和移动端共用的全局导航样式。菜单权限、路由权限和现有业务功能保持不变。

## 方案评审

### 方案一：复用租户系统配置

使用现有 `xianyu_sys_setting` 保存版本化菜单布局 JSON，由现有 MyBatis Plus 租户拦截器自动添加 `tenant_id` 条件。前端维护唯一菜单目录，导航和菜单管理页面共用该目录。

优点是无需数据库迁移和新依赖，租户隔离、配置读写、错误处理均可复用现有能力；新增菜单可通过布局归一化自动补齐。缺点是布局内容以 JSON 保存，不适合复杂菜单权限建模，但本需求只涉及顺序，JSON 足够。

### 方案二：新增菜单排序表

为模块和菜单项分别保存租户、菜单标识、父级标识和排序值。

优点是数据库查询和批量管理更灵活；缺点是需要迁移、实体、Mapper、服务和接口，当前没有跨租户统一运营菜单的需求，成本明显高于收益。

### 方案三：浏览器本地存储

将顺序保存在 `localStorage`。

优点是实现最短；缺点是无法跨浏览器和设备同步，也不属于服务端租户隔离配置，不满足需求。

采用方案一。

## 架构

### 菜单目录

新增纯 TypeScript 菜单目录，定义模块标识、模块名称、菜单标识、路径、权限和图标键。默认包含：

1. 概览：面板、数据看板
2. 账号与连接：闲鱼账号、连接管理
3. 商品与获客：商品管理、商品发布、运营中心、商机发掘、全站比价、货源库、工作流
4. 成交履约：卡密仓库、固定内容模板、自动发货、订单与评价
5. 客户运营：消息管理、买家管理、自动回复
6. 系统：操作日志、通知与诊断、系统设置、账号与权限

布局结构使用 `version + groups`，每个模块保存模块标识和菜单标识数组。归一化逻辑过滤未知项、重复项和跨模块项，并在末尾补齐新模块、新菜单。配置为空或 JSON 损坏时返回默认布局。

### 租户配置

使用配置键 `menu_layout`。后端当前用户接口附带当前租户菜单布局，避免导航组件挂载后再次请求和出现顺序闪动。保存继续复用 `/api/setting/save`，由 `xianyu_sys_setting` 的 `(tenant_id, setting_key)` 唯一键和租户拦截器保证隔离。

### 全局导航

`NavMenu.vue` 改为根据菜单目录和归一化布局渲染：

- 先按租户布局排列模块和菜单，再执行现有菜单权限过滤。
- 没有可见菜单的模块不渲染。
- 平台管理员菜单仍只对管理员显示。
- 电脑端侧边栏和手机、平板抽屉继续共用同一个组件。
- 菜单图标统一为现有 SVG 组件，激活态使用简洁色块和左侧指示条，模块标题使用轻量分组样式。
- 使用 Vue `TransitionGroup` 为租户布局变化提供位移动画，并尊重系统减少动态效果设置。

### 菜单管理

系统设置新增“菜单管理”面板：

- 模块卡片可拖动排序。
- 模块内菜单可拖动排序，不允许跨模块移动。
- 拖动进入目标项时实时换位，使用 `TransitionGroup` 平滑移动其他项。
- 上移、下移按钮作为键盘和触屏降级方式。
- “恢复默认”只更新草稿，“保存排序”统一提交一次。
- 保存成功后立即更新全局权限状态中的布局，侧边栏无需刷新即可按新顺序展示。
- 保存期间禁用重复提交；配置不可写时停用保存操作。

## 数据流

1. 路由守卫调用当前用户接口。
2. 后端在当前租户上下文读取 `menu_layout`，与用户名、角色、权限一起返回。
3. 前端权限状态缓存布局字符串。
4. 导航组件归一化布局，过滤当前账号不可见菜单后渲染。
5. 菜单管理面板从同一布局生成草稿。
6. 保存时序列化草稿并调用现有配置接口。
7. 保存成功后更新权限状态，导航组件响应式重排。

## 异常处理

- 缺少配置、空配置、非法 JSON、未知模块或未知菜单均回退或补齐默认布局。
- 重复模块和重复菜单只保留第一次出现的位置。
- 菜单只能在所属模块内排序，避免布局配置改变权限或信息架构。
- 配置加载失败不阻断登录和导航，继续使用默认顺序。
- 保存失败保留当前草稿并显示现有全局提示。

## 性能

- 当前用户请求同时返回布局，不新增导航加载请求。
- 归一化只处理固定数量菜单，使用 `Set` 去重。
- 拖动只更新当前模块或模块列表，不触发业务页面刷新。
- 不引入第三方拖动库，减少包体和运行时开销。

## 测试范围

### 开发验证

- 先用临时测试覆盖默认布局、非法 JSON、去重、未知项过滤、新项补齐和同级移动。
- 临时测试完成后删除，再执行 TypeScript 类型检查和正式前端构建。
- 使用 JDK 21 执行后端测试，验证当前用户 DTO 和控制器改动可编译。

### 用户验收

- 两个租户保存不同布局后，各自登录只看到自己的顺序。
- 模块和模块内菜单均可拖动，上移、下移可替代拖动。
- 保存后侧边栏立即平滑重排，刷新和重新登录后保持顺序。
- 恢复默认后保存可回到默认顺序。
- 菜单权限、管理员菜单、桌面侧边栏和移动抽屉行为保持正确。
